# Build vs Buy — Solana smart-money система

> Политика: дефолт `BUILD`. Время = 0 (не фактор). Минимизировать **регулярные** затраты.
> `BUY` только если ОБА: (а) самому реально нельзя/непрактично **И** (б) DIY **сильно** просядет
> по качеству для конечной цели. Разделяем: `BUILD` (self-host) · `FREE-TIER` (бесплатный тариф,
> не покупка) · `BUY` (регулярный платёж).
> Все лимиты сверены по докам 01.07.2026; непроверенное помечено `⚠️ проверить`.

---

## 0. Итоговый вывод (TL;DR)

- **Мандаторных `BUY` — ноль.** Ни один модуль не обязан быть покупкой под твоими правилами.
- **Пол регулярных затрат = $0/мес** сверх уже оплаченного VPS. Реальные деньги появляются только
  при включённом авто-исполнении (J) — и это **сетевые/priority fees Solana** (центы за tx) +
  протокольные DEX-комиссии (их платят все, включая боты), а НЕ комиссия инструмента.
- Единственная честная quality-delta, способная в будущем оправдать доплату — **латентность
  реалтайма для конкурентного авто-исполнения** (free WebSocket 150–300 мс vs платный gRPC <100 мс).
  Это **триггер на потом**, не сейчас, и решается тарифом Helius Developer **$49/мес**, а не %-комиссией.

**Пруфы лимитов:**
- Public RPC `api.mainnet-beta.solana.com`: 100 req/10s/IP, WS деприоритизируется при конгестии, лаг 150–300 мс → только dev/fallback.
- Helius **Free**: 1M кредитов/мес, 10 RPC req/s, 2 DAS req/s, LaserStream WebSocket (стандартные Solana методы). `transactionSubscribe` (enhanced) и gRPC — с Developer **$49/мес**. Стриминг тарифицируется ~20 кредитов/МБ (~$100/ТБ).
- Dune **Free**: 2500 кредитов/мес + API + 10 приватных запросов.
- Bitquery **Free Developer**: 10K поинтов **только первый месяц**, 2 тест-стрима; 1 стрим×10 мин = 400 поинтов → ~250 мин суммарно. Для 24/7 непригодно.

При максимально кастомном варианте регулярно платится:

| Статья | $/мес | Комментарий |
|--------|-------|-------------|
| VPS | **$0 marginal** | уже оплачен (Hostkey/Senko), Docker-паттерн есть |
| Данные (Helius Free + Dune Free + RugCheck public) | **$0** | в рамках free-лимитов |
| Telegram-доставка | **$0** | |
| Discovery (Контур 1) | **$0** | Dune free, чанкование |
| Live-мониторинг + сигналы (Контур 2) | **$0** | Helius Free WS |
| Авто-исполнение (J), **только если включено** | сетевые+priority fees Solana (центы/tx) + ATA-рента ~0.002 SOL/токен разово + протокольные DEX-fees (платят все) | **не подписка**; комиссия инструмента = 0 при прямой интеграции |

**Регулярный пол = $0/мес.** Деньги = только per-trade сетевые издержки при живом J, которые несёт любой участник рынка.

## 5. Компоненты с вердиктом `BUY`

**Честно: ноль обязательных `BUY`.** Ни по одному модулю не выполняется условие 2(а)+2(б) одновременно —
всё либо воспроизводимо своим кодом (публичный on-chain), либо покрывается free-тарифом.

Ближайшие к `BUY` «триггеры на будущее» (сейчас НЕ покупаем):

## 8. Фазовая дорожная карта (порядок важнее скорости)

**Фаза 0 — фундамент данных + движок A.** Настроить L1 (Helius Free RPC ключ) + L2 (DuckDB на VPS).
Построить Модуль A: realized P&L по одному токену из сырых трейдов. *Гейт:* корректный P&L на 2–3
эталонных токенах, сверенный вручную.

**Фаза 1 — discovery (B→C→D→E) + валидация смещений.** Universe с мёртвыми токенами (Dune),
кросс-токенная агрегация, copyability/bot-флаги, кластеризация. train/validation split по дате T.
*Гейт:* edge переживает validation-окно; `report.md` с разбором survivorship/look-ahead и знаменателя.
**Не идём дальше, если edge не подтверждён.**

**Фаза 2 — live (F→G→H→I).** Helius Free WS по watchlist, сигнал + конфлюенс, safety-скрин, Telegram.
*Гейт:* стабильный стрим, конфлюенс работает, дубли не шлются, safety отрабатывает перед `strong`.

**Фаза 3 — исполнение (J), опционально.** Jupiter Swap API `platformFeeBps=0`, сначала **PAPER**
(лог сделок без денег) для валидации сигналов, затем малый капитал. *Гейт:* PAPER-PnL по сигналам
положителен на достаточной выборке до любого реального капитала.
