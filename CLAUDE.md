## Почему закрыт

176 сделок настоящими деньгами за два независимых окна (10.08 и 13.08): **−$0.72 на
сделку**. Порог окупаемости — разрыв исполнения 0.911, фактический 0.886.

Все три рычага исправления замерены и отвергнуты:
- **отбор по признакам входа** — каждый фильтр делает хуже (−$1.6…−$2.6);
- **правило выхода** — парно лучше лишь в 39% случаев, медиана разницы −5.6%;
- **скорость** — недобор ровный по всем интервалам задержки.

Причина структурная: признак, предсказывающий крупный выигрыш, предсказывает и
крупный провал исполнения. Разрыв по вёдрам исхода 0.923 / 0.928 / 0.809 / **0.789**.

Круг издержек здесь 5.5–8.6% и сопоставим со всем преимуществом стратегии. Включать
обратно можно только при новом источнике преимущества, а не после хорошей серии.

Разбор целиком — `docs/live_readiness.md`. Преемник — проект `wake`.

## Чего делать не надо

- переигрывать правило выхода, отбор акторов, пороги — всё замерено, см. память;
- доверять полю `realized_model`: модельные цены недостижимы по построению, это
  бенчмарк, а не результат;
- считать окупаемость по `exec_gap` — он арифметический, для этого есть `разрыв_к`.
